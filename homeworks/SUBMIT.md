# Как сдавать домашнее задание

У каждого студента один личный закрытый репозиторий на весь курс: `rl-<ваш логин>`. Его видите только вы и преподаватель. Каждая домашка (блок из двух лекций) появляется в нём отдельной папкой: `hw1/`, `hw2/`, … Git знать не обязательно: всё делается на сайте github.com.

## Один раз в начале курса

1. **Аккаунт на GitHub.** Если его нет, зарегистрируйтесь на [github.com](https://github.com/signup), понадобится только почта.
2. **Логин в таблицу.** Впишите свой логин в таблицу группы (ссылку даст преподаватель). Логин — это имя после `github.com/` в адресе вашей страницы: у страницы `github.com/ivan-petrov` логин `ivan-petrov`. Ещё его видно, если нажать на аватар в правом верхнем углу github.com.
3. **Личный код для квизов** лежит в вашем репозитории в файле `МОЙ_КОД_ДЛЯ_КВИЗОВ.txt` (появится вместе с первой домашкой). Код вида `KUZN56` вводится на странице квиза в зачётном режиме. Он личный — не передавайте его другим.
4. **Примите приглашение.** На почту, привязанную к GitHub, придёт письмо о приглашении в репозиторий `rl-<ваш логин>` организации `rl-course-misis`. Нажмите в нём **View invitation → Accept invitation**. Письма нет — откройте [github.com/notifications](https://github.com/notifications) или спросите преподавателя. Приглашение одно на весь курс.

## На каждый блок

### 1. Найдите задание

Когда преподаватель выдаёт блок, в вашем репозитории появляется папка `hwN/` (N — номер блока):

* `hwN/homework.ipynb` — задание;
* `hwN/quiz/weekXX.txt` — два файла для кодов квизов по лекциям блока (для блока 1 — `week01.txt` и `week02.txt`).

Папки прошлых блоков остаются на месте, их не трогайте.

### 2. Решите задание

* Скачайте `hwN/homework.ipynb`: откройте файл в репозитории, затем кнопка **⋯ → Download** справа сверху. Либо откройте его в Google Colab по кнопке в первой ячейке ноутбука.
* Решите задания, помеченные `TODO`. Под многими стоит `assert`: если ячейка выполнилась без ошибки, эта часть засчитана. Текстовые ответы пишите в markdown-ячейках вместо `TODO`.
* **Перед сдачей выполните ноутбук целиком:** в Jupyter — *Kernel → Restart & Run All*, в Colab — *Среда выполнения → Перезапустить сеанс и выполнить все*. Сохраните файл. Из Colab: *Файл → Скачать → Скачать .ipynb*.

### 3. Пройдите квизы

На [странице квизов](https://ilyachichkanov.github.io/Reinforcement-learning/) выберите лекцию, режим **«Зачёт»** и введите личный код. После последнего вопроса нажмите «Скопировать» — получите код результата вида `W1:IVAN23:BDAACBDABCAD:7F3A`. Так для каждой из двух лекций блока.

Потренироваться можно в режиме «Тренировка» сколько угодно, в зачёт идёт только код из режима «Зачёт».

### 4. Загрузите работу

1. Откройте свой репозиторий на github.com и **зайдите в папку блока `hwN/`**.
2. **Ноутбук:** находясь в `hwN/`, нажмите *Add file → Upload files*, перетащите решённый `homework.ipynb` (имя файла не меняйте), внизу нажмите **Commit changes**. Старый файл заменится новым. Если загрузить из корня репозитория, файл ляжет не туда — проверка его не увидит.
3. **Коды квизов:** откройте `hwN/quiz/weekXX.txt`, нажмите карандаш (*Edit*), вставьте код отдельной строкой вместо строки `вставьте сюда код результата`, нажмите **Commit changes**. То же для второго файла.

Если умеете работать с git, можно сделать то же через `git clone` / `git push` — результат одинаковый.

### 5. Посмотрите на автопроверку

Через минуту-две после загрузки рядом с последним изменением в репозитории появится значок:

* ✅ **зелёная галочка** — блок сдан полностью: ноутбук выполнен целиком, заготовок и упавших ячеек нет, оба кода квизов вставлены и скопированы без ошибок;
* ❌ **красный крестик** — чего-то не хватает. Нажмите на крестик → *Details*, внизу страницы будет список того, что исправить.

Зелёная галочка значит «сдано полностью», а не «всё верно»: правильность решений и текстовые ответы проверяет преподаватель.

## Частые проблемы

| Что видите | Что делать |
|---|---|
| «ноутбук не запускался» или «не выполнено ячеек с кодом» | Вы сохранили файл без выводов или выполнили не всё. Выполните все ячейки заново и загрузите файл ещё раз. |
| «ячейки с кодом, упавшие с ошибкой» | В перечисленных ячейках ошибка. Номер — порядковый номер ячейки с кодом, считая сверху. |
| «остались незаполненные заготовки» | В перечисленных ячейках остались `raise NotImplementedError`, `# TODO` или `x = ...`. Допишите решение и удалите заготовку. |
| «код не вставлен» | В `hwN/quiz/weekXX.txt` нет кода результата. Вставьте его вместо строки-подсказки. |
| «контрольная сумма не сошлась» | Код квиза скопирован не целиком. Скопируйте его кнопкой «Скопировать» на странице квиза. |
| Нет письма-приглашения | Проверьте, что логин в таблице без опечаток, и напишите преподавателю. |
| «файла нет» про `hwN/homework.ipynb` | Ноутбук загружен не в ту папку. Откройте `hwN/`, загрузите файл туда, лишнюю копию в корне удалите. |
| Нет папки нового блока | Блок ещё не выдан — дождитесь объявления преподавателя. |

## Сроки

Исправлять и загружать заново можно сколько угодно раз до дедлайна. В зачёт идёт последняя версия, загруженная **до** дедлайна. Дедлайн каждого блока — в таблице в [`homeworks/README.md`](README.md), веса заданий — в заголовках частей ноутбука.
