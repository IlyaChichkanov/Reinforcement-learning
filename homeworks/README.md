# Домашние задания

Домашнее задание выдаётся **раз в две недели** и охватывает обе лекции блока. Квизы остаются после каждой лекции, поэтому к каждой домашке сдаются два кода результата.

| Блок | Лекции | Задание | Квизы |
|---|---|---|---|
| 1 | 1–2: Cross-Entropy, оценка политики, своя среда, уравнения Беллмана | [`hw1/homework.ipynb`](hw1/homework.ipynb) | `quiz/week01.txt`, `quiz/week02.txt` |

## Как устроено задание

* **100 баллов** в основных частях и до 30 бонусных. Вес каждой части указан в заголовке.
* Части с `assert` проверяются автоматически при запуске ячейки: если `assert` не упал, часть засчитана. Текстовые ответы и графики проверяет преподаватель.
* Ноутбук открывается в Google Colab по кнопке в начале; первая ячейка сама ставит недостающие пакеты.

## Как сдавать

Через GitHub Classroom: по ссылке-приглашению у вас появится личный репозиторий с ноутбуком и файлами для кодов квизов. Порядок сдачи описан в его README, схема для преподавателя — в [`../classroom/SETUP.md`](../classroom/SETUP.md).
