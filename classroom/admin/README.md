# Пульт преподавателя курса RL

Закрытый репозиторий. Студенты его не видят. Здесь:

* `students.csv` — ФИО и GitHub-логины (выгрузка из таблицы логинов);
* `blockN/<логин>/` — сданные работы блока N, собираются автоматически каждый час;
* `blockN-deadline/<логин>/` — версии на момент дедлайна (собираются вручную, см. ниже);
* `blockN/grades.csv`, `blockN/<логин>/feedback.md` — оценки и комментарии после проверки.

У каждого студента один репозиторий на курс — `rl-<логин>`; домашки выдаются в него папками `hw1/`, `hw2/`, …

## Кнопки (вкладка Actions)

| Workflow | Когда запускать |
|---|---|
| **Создать репозитории студентов** | В начале курса и каждый раз, когда в `students.csv` появились новые логины. Повторный запуск ничего не ломает. |
| **Выдать блок** | Когда открываете новую домашку: номер блока → в каждый репозиторий добавится `hwN/`. Новым студентам — запустить ещё раз: у остальных ничего не перезапишется. |
| **Кто принял приглашение и сдавал** | Посмотреть, кто ещё не принял приглашение и кто уже загружал работу по блоку. |
| **Собрать работы** | Работает сам каждый час. Вручную — после дедлайна с полем `before` (например `2026-10-28T23:59:59+03:00`): версии на момент дедлайна лягут в `blockN-deadline/`. |

Запуск: Actions → нужный workflow слева → **Run workflow** → заполнить поля → **Run workflow**. Отчёт — на странице запуска, в разделе *Summary*. «Создать» и «Выдать» можно сначала запустить с галочкой *dry_run* — покажут, что сделают, ничего не меняя.

## Настройки

* Секрет **`ADMIN_TOKEN`** (Settings → Secrets and variables → Actions → Secrets): токен преподавателя, как его получить — в [`SETUP.md`](https://github.com/IlyaChichkanov/Reinforcement-learning/blob/main/classroom/SETUP.md).
* Переменная **`CURRENT_BLOCK`** (там же, вкладка Variables): номер блока, который собирается каждый час. Если её нет — 1.
