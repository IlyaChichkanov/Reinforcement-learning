# Домашнее задание по курсу Reinforcement Learning

Это ваш личный репозиторий для сдачи одного блока курса (две лекции). Его видите только вы и преподаватель. Подробная инструкция и разбор частых ошибок — [«Как сдавать домашнее задание»](https://github.com/IlyaChichkanov/Reinforcement-learning/blob/main/homeworks/SUBMIT.md).

## Что нужно сделать

1. **Решите `homework.ipynb`.** Скачайте его (кнопка **⋯ → Download** на странице файла) или откройте в Colab по кнопке в первой ячейке. Задания помечены `TODO`; если ячейка с `assert` выполнилась без ошибки, эта часть засчитана. Текстовые ответы пишите в markdown-ячейках вместо `TODO`.
2. **Выполните ноутбук целиком** и сохраните: *Restart & Run All* в Jupyter или *Перезапустить сеанс и выполнить все* в Colab.
3. **Пройдите оба квиза** блока в режиме **«Зачёт»** на [странице квизов](https://ilyachichkanov.github.io/Reinforcement-learning/) с вашим личным кодом и скопируйте коды результатов.
4. **Загрузите работу здесь, на github.com:**
   * ноутбук — *Add file → Upload files*, перетащите `homework.ipynb` (имя не меняйте), **Commit changes**;
   * коды квизов — откройте `quiz/weekNN.txt`, карандаш (*Edit*), вставьте код вместо строки-подсказки, **Commit changes**. Так для обоих файлов.

   Умеете работать с git — можно через `git push`, результат тот же.

## Автопроверка

Через минуту-две после загрузки рядом с последним изменением появится значок:

* ✅ — сдано полностью: ноутбук выполнен, заготовок и упавших ячеек нет, оба кода квизов на месте;
* ❌ — что-то не так: нажмите на крестик → *Details*, внизу будет список, что поправить.

Галочка значит «сдано полностью», а не «решено верно»: правильность и текстовые ответы проверяет преподаватель.

Загружать заново можно сколько угодно раз. В зачёт идёт последняя версия, загруженная до дедлайна.
