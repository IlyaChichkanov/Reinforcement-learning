# Домашнее задание по курсу Reinforcement Learning

В этом репозитории вы сдаёте одну неделю курса: ноутбук с заданиями и код результата квиза.

## Что нужно сделать

1. **Решите ноутбук** `homework.ipynb`. Задания помечены `TODO`; часть проверок оформлена как `assert` — если ячейка выполнилась без ошибки, эта часть засчитана. Текстовые ответы пишите прямо в markdown-ячейках вместо слова `TODO`.
2. **Выполните ноутбук целиком** перед сдачей: «Restart & Run All». Автопроверка смотрит, что все ячейки выполнены и ни одна не упала.
3. **Пройдите квиз** по лекции этой недели в **зачётном** режиме: [страница квизов](https://ilyachichkanov.github.io/Reinforcement-learning/). Введите личный код, который выдал преподаватель, ответьте на все вопросы, нажмите «Завершить» и скопируйте код результата.
4. **Вставьте код результата** в файл `quiz/weekNN.txt` — одной строкой вместо подсказки.
5. **Отправьте работу**: `git add -A && git commit -m "Неделя 1" && git push`. Автопроверка запустится сама, а результат появится в pull request с названием «Feedback».

## Что проверяет автопроверка

* код результата квиза разбирается и не испорчен при копировании (баллы за квиз она не считает — это делает преподаватель);
* ноутбук выполнен целиком, в нём не осталось `raise NotImplementedError` и ячеек с ошибками.

Зелёная галочка не означает, что задание решено верно: правильность проверяет преподаватель. Красная означает, что работу точно надо поправить.

## Если что-то не сходится

* «контрольная сумма не сошлась» — код скопирован не целиком. Пройдите квиз заново и скопируйте код кнопкой.
* «ноутбук не запускался» — вы сохранили файл без выводов. Выполните «Restart & Run All» и сохраните ещё раз.
* Дедлайны, вес заданий и порядок пересдачи — в `Syllabus.md` основного репозитория курса.
