# Домашние задания по курсу Reinforcement Learning

Это ваш личный репозиторий на весь курс. Его видите только вы и преподаватель. Каждая домашка появляется здесь отдельной папкой: `hw1/`, `hw2/`, … Подробная инструкция и разбор частых ошибок — [«Как сдавать домашнее задание»](https://github.com/IlyaChichkanov/Reinforcement-learning/blob/main/homeworks/SUBMIT.md).

Личный код для квизов — в файле `МОЙ_КОД_ДЛЯ_КВИЗОВ.txt` в корне репозитория.

## Что в папке домашки

```
hwN/homework.ipynb        задание
hwN/quiz/weekXX.txt       сюда — коды результатов квизов по двум лекциям блока
```

## Как сдать блок

1. **Решите `hwN/homework.ipynb`.** Скачайте его (на странице файла кнопка **⋯ → Download**) или откройте в Colab по кнопке в первой ячейке. Задания помечены `TODO`; если ячейка с `assert` выполнилась без ошибки, эта часть засчитана. Текстовые ответы пишите в markdown-ячейках вместо `TODO`.
2. **Выполните ноутбук целиком** и сохраните: *Restart & Run All* в Jupyter или *Перезапустить сеанс и выполнить все* в Colab.
3. **Пройдите оба квиза** блока в режиме **«Зачёт»** на [странице квизов](https://ilyachichkanov.github.io/Reinforcement-learning/) с вашим личным кодом и скопируйте коды результатов.
4. **Загрузите работу здесь, на github.com:**
   * ноутбук — откройте папку `hwN/`, затем *Add file → Upload files*, перетащите `homework.ipynb` (имя не меняйте), **Commit changes**. Файл должен оказаться именно в `hwN/`, а не в корне;
   * коды квизов — откройте `hwN/quiz/weekXX.txt`, карандаш (*Edit*), вставьте код вместо строки-подсказки, **Commit changes**. Так для обоих файлов.

   Умеете работать с git — можно через `git push`, результат тот же.

## Автопроверка

Через минуту-две после загрузки рядом с последним изменением появится значок:

* ✅ — блок сдан полностью: ноутбук выполнен, заготовок и упавших ячеек нет, оба кода квизов на месте;
* ❌ — что-то не так: нажмите на крестик → *Details*, внизу будет список, что поправить.

Галочка значит «сдано полностью», а не «решено верно»: правильность и текстовые ответы проверяет преподаватель.

Загружать заново можно сколько угодно раз. В зачёт идёт последняя версия, загруженная до дедлайна.
