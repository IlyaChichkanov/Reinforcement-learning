# Квизы по лекциям

Короткие квизы для проверки понимания лекции: по двенадцать вопросов с четырьмя вариантами ответа. Проходятся за десять минут — на паре или дома.

## Как этим пользоваться

**Студенту.** Откройте [страницу квизов](https://ilyachichkanov.github.io/Reinforcement-learning/). Два режима:

* **Тренировка** — разбор появляется сразу после ответа, попытки не ограничены, ничего никуда не отправляется.
* **Зачёт** — правильность не показывается; после ответа на все вопросы страница выдаёт **код результата** вида `W1:IVAN23:BDAACBDABCAD:7F3A`, который вы вставляете в файл `quiz/weekNN.txt` своего репозитория с домашним заданием.

**Преподавателю.** Разбор всей схемы — в [`../classroom/SETUP.md`](../classroom/SETUP.md). Коротко:

```bash
uv run python tools/make_roster.py students.csv       # личные коды студентам
uv run python tools/build_quiz_page.py                # пересобрать страницу
uv run python tools/grade_quiz.py collected/ --roster roster.csv
```

## Устройство файлов

Каждая неделя — один файл `weekNN.json`:

```json
{
  "week": 1,
  "title": "Знакомство с обучением с подкреплением",
  "lecture": "01-intro/lecture/lecture.ipynb",
  "pass_score": 8,
  "questions": [
    {
      "id": "w1q03",
      "topic": "Интерфейс Gymnasium",
      "text": "Что возвращает env.step(action) и в каком порядке?",
      "options": ["...", "...", "...", "..."],
      "answer": 1,
      "explain": "Разбор, который студент видит после ответа.",
      "ref": "Ключевые понятия: действие, награда, переход"
    }
  ]
}
```

* `answer` — индекс правильного варианта, с нуля. На странице варианты помечены буквами A, B, C, D — они же попадают в код результата.
* `ref` — название раздела лекции, а не его номер: нумерация разделов может меняться.
* `pass_score` — сколько верных ответов считается зачётом.

Чтобы добавить неделю, положите рядом `week03.json` и выполните `uv run python tools/build_quiz_page.py`: страница подхватит новый файл и добавит вкладку сама.

## Как составлены вопросы

Каждый вопрос опирается на конкретное утверждение лекции, а неверные варианты — на заблуждения, которые лекция разбирает явно: что прорубь не штрафует, чем `truncated` отличается от `terminated`, почему квантиль дал нулевой порог, почему нулевая вероятность действия опаснее маленькой, почему соперник в шахматах — часть среды. Поэтому в квизе не встретить вопроса на память о числе, которое в лекции не проговаривалось.

## Честная оговорка про списывание

Страница работает без сервера, поэтому правильные ответы физически лежат в ней (иначе тренировочный режим невозможен), а файлы `week*.json` открыты в репозитории. Контрольная сумма в коде результата защищает от опечаток при копировании, а не от подделки.

Квиз задуман как проверка понимания и повод разобрать трудные места на семинаре. Если нужен защищённый зачёт — проводите его очно и принимайте код результата с экрана.
